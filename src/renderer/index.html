Atajos de teclado

  • → Espacio AvPág: siguiente página
  • ← RePág: página anterior
  • + / −: tamaño de letra
  • T: cambiar el color de la página (blanco, sepia, gris, oscuro, negro) · D: claro/oscuro
  • P: pausar/reanudar el avance automático
  • M: ajustes · Ctrl+O: abrir libro
  • Esc: ocultar (modo discreto)

Para mover la ventana, arrástrala desde la barra superior. Para cambiar su tamaño, arrastra un borde o una esquina.
